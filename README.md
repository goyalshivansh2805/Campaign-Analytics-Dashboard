# Campaign Analytics Dashboard

A full-stack web application for viewing and filtering marketing campaign data. Built with **Next.js** for the frontend and **FastAPI + PostgreSQL** for the backend.

---

## 🚀 Features

- **Frontend:** Displays campaigns in a filterable table (`Active`, `Paused`).
- **Backend:** Provides mock campaign data via a REST API.

---

## 🛠 Tech Stack

- **Frontend:** Next.js, TailwindCSS
- **Backend:** FastAPI, PostgreSQL
- **Deployment:** Vercel (frontend), Railway (backend)
