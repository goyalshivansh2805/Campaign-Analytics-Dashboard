# 📊 Marketing Campaigns Dashboard – Frontend

A sleek frontend application built with **Next.js** and **TailwindCSS** that displays marketing campaign data in a responsive table with filtering options.

---

## 🚀 Features

- Displays campaign data in a styled table
- Filters by campaign status (`Active`, `Paused`)
- Fully responsive layout
- Modular file structure with reusable components
- Integrated with FastAPI mock backend

---

## 🛠 Tech Stack

- **Framework:** Next.js (React)
- **Styling:** TailwindCSS
- **Language:** TypeScript
- **State Management:** React `useState`, `useEffect`

---

## 📦 Installation

```bash
git clone https://github.com/goyalshivansh2805/Campaign-Analytics-Dashboard.git
cd Campaign-Analytics-Dashboard/frontend
npm install
```

---

## 🧪 Development

```bash
npm run dev
```

App will run locally at:  
**[http://localhost:3000/](http://localhost:3000/)**
